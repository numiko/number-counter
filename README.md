# Number Counter

A package to animate numbers — most predominantly used on our statistics slice.

## Features

- Automatically detects and animates numbers in text when they scroll into view.
- Customizable duration and starting values for smooth counting animations.

## Installation

The package can be installed using the semantic version.

`npm install ssh://git@bitbucket.org:numiko/number-counter.git##semver:<VERSION>`

## API

See [documentation](https://bitbucket.org/numiko/number-counter/commits/branch/main/) for more detail on how to use the package.
