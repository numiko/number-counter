# Number Counter

A package to animate numbers — most predominantly used on our statistics slice.

## Features

- Automatically detects and animates numbers in text when they scroll into view.
- Customizable duration and starting values for smooth counting animations.

## Installation

`npm i @numiko/number-counter`

## API

See [documentation](https://v0.3.0--numiko-number-counter.netlify.app) for more detail on how to use the package.
